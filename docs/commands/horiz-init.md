# horiz-init (初期化システム)

`horiz-init` は、HorizOS のユーザーランドにおける最初期プロセス（PID 1相当）として動作し、システムのセットアップとユーザーセッションの管理、重要指標の監視、電源制御およびサービス監視を行うカスタム実装の Init システムである。

## 主な役割と機能

### 1. 仮想ファイルシステム (VFS) のマウント
システムの動作に必要な仮想ファイルシステムをセキュアなフラグ付きでマウントする。
- **マウント対象**: `/proc`, `/sys`, `/dev`, `/tmp`
- **セキュリティフラグ**: `MS_NOSUID`, `MS_NODEV`, `MS_NOEXEC` 等を付与。

### 2. インターフェースの初期化とサービス監視 (Supervision)
- ネットワークのループバックインターフェース (`lo`) をセットアップ。
- `/etc/horiz/services.conf` からサービス設定を読み込み、バックグラウンドでのプロセス自動起動および死活監視を実施。

### 3. セキュアなログインと特権放棄
- ブート完了後、コンソールに `--- HorizOS Login ---` プロンプトを表示。
- 入力されたパスワードは `horiz-auth` クレートを利用して検証（10,000回の SHA-256 ストレッチングと定数時間比較）。
- 認証成功後、`/etc/passwd` から UID/GID を取得し `setgid`/`setuid` により root 特権を放棄した上で標準シェル (`/bin/sh` -> `horiz-sh`) を起動。

### 4. システムシャットダウン・再起動制御
- ログインプロンプトにおいて `reboot` または `poweroff` / `shutdown` が入力された場合、プロセスへの `SIGTERM`/`SIGKILL` 送信および `sync` を実施後、システムコールを呼び出して安全に再起動またはシャットダウンを行う。

### 5. 常駐監視とゾンビプロセスの回収
- 親プロセスとして無限ループで待機し、定期的に `waitpid` を呼び出して終了した子プロセスのリソースを回収する。

### 6. 構造化監査ロギング
- システムの重要イベントを `/var/log/system.log` および `/var/log/audit.log` にタイムスタンプ付きで出力。
