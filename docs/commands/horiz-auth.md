# horiz-auth (認証ライブラリおよび passwd ユーティリティ)

`horiz-auth` は、HorizOS 環境下においてシステムへのログインパスワード認証およびパスワード変更を安全に処理するために設計された、独自のセキュリティ認証ライブラリおよび CLI ツールである。

## 主要な機能と実装

### 1. タイミング攻撃への耐性
- 定数時間比較 (Constant-time Comparison) による XOR ベースの比較処理。

### 2. 強固なハッシュ化とストレッチング
- 独自実装の SHA-256 と 10,000 回のストレッチング。

### 3. セキュアなソルト生成
- `/dev/urandom` を参照する CSPRNG ソルト生成 (16バイト)。

### 4. パスワード変更 API (`change_password`) と `passwd` ツール
- `passwd` コマンドラインツールを提供。
- 旧パスワードの認証検証成功後、新規ランダムソルトで 10,000 回ストレッチングしたハッシュを計算し、`/etc/shadow` をアトミックに安全更新。

```bash
passwd
```
