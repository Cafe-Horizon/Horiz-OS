# horiz-sh (シェル)

`horiz-sh` は、HorizOS 環境下でインタラクティブなコマンドライン操作インターフェースを提供する、軽量かつカスタム仕様のシェル実装である。

## 主な機能

- **カスタムプロンプト**: `/etc/hostname` ファイルから読み込んだホスト名、環境変数 `$USER` で指定されたログインユーザー名、現在のワーキングディレクトリ (CWD) を用いて `[user@hostname] /path/to/cwd #` 形式のプロンプトを表示する。
- **組み込みコマンド (Builtins)**:
  - `exit`: シェルセッションを終了し、`horiz-init` の親プロセスへ処理を返す。
  - `cd [dir]`: カレントディレクトリを指定パス、またはデフォルトの `/` へ移動する。
  - `whoami`: 現在シェルプロセスを実行しているユーザー名を表示する。
  - `version`: シェルのバージョン情報とビルドエディションを表示する。
  - `export [KEY=VALUE...]`: シェル内で環境変数を動的に定義し、外部コマンドに継承する。
  - `unset [KEY...]`: 指定された環境変数を削除する。
  - `history`: 過去に入力されたコマンド履歴を表示する。
- **パイプラインおよびリダイレクト**:
  - `|` を用いたコマンド間での標準入出力パイプライン制御。
  - `>`, `>>`, `<` を用いた標準出力の新規上書き・追記保存・標準入力リダイレクト。
- **変数展開と履歴永続化**:
  - トークン内の `$VAR` 文字列を動的に環境変数値へと置換。
  - 入力履歴を `~/.horiz_history` へ自動追記保存。
- **シグナルハンドリング**:
  - シェル本体は `SIGINT` (Ctrl+C) を無視し、実行中のフォアグラウンド子プロセスのみを安全に中断させる。
