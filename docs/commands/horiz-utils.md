# horiz-utils (標準ユーティリティ群)

`horiz-utils` は、HorizOS 環境下で日常的に利用される POSIX ライクな基本コマンドを提供する、ゼロ依存のユーティリティコレクションバイナリである。

単一の実行可能ファイルとして提供され、シンボリックリンクまたは呼び出し元の名前 (`env::args()`) に応じて各サブコマンドの振る舞いを決定する。(BusyBox等に似た設計である)

## 収録されているコマンド

以下のコマンド名で `horiz-utils` を呼び出すと、それぞれの機能が実行される。

### 1. `ls` (ディレクトリ一覧表示)

現在のワーキングディレクトリ (CWD) または引数で指定したパス内のファイルおよびディレクトリの一覧を表示する。

```bash
ls
ls /var/log
```

### 2. `cat` (ファイル内容の出力)

引数として与えられたすべてのファイルパスを順に開き、その内容を標準出力（コンソール）へ結合して表示する。

```bash
cat /etc/hostname
cat /var/log/system.log /var/log/audit.log
```

### 3. `echo` (文字列の出力)

引数として渡されたすべての文字列をスペース区切りで結合し、末尾に改行を付与して標準出力へ書き出す。設定値の確認やシェルスクリプト内のログ出力等に利用される。

```bash
echo "Hello HorizOS World!"
echo $USER
```

### 4. `chmod` (ファイルパーミッションの変更)

8進数形式の指定に基づいて、ファイルやディレクトリのアクセス権限を変更する。Unix 標準の `chmod` と同様に機能し、複数のパスを一度に処理することも可能である。

```bash
chmod 755 /usr/bin/horiz-init
chmod 644 /etc/passwd /etc/group
```

### 5. `date` (日時・時刻の表示)

現在のシステム日時を東京時間（JST: UTC+9）でフォーマットして標準出力へ出力する。

```bash
date
# 出力例: Thu Aug 13 23:16:28 JST 2026
```

## ソースコード構造

`horiz-utils` は保守性と拡張性を高めるため、サブコマンドごとにモジュール分割されている。

- `src/lib.rs`: モジュール構成の定義および外部向け API の re-export
- `src/ls.rs`: ディレクトリ一覧表示 (`ls`)
- `src/cat.rs`: ファイル内容出力 (`cat`)
- `src/echo.rs`: 文字列出力 (`echo`)
- `src/chmod.rs`: ファイル権限変更 (`chmod`)
- `src/date.rs`: 日時表示・タイムゾーン/TZif解析 (`date`)
- `src/main.rs`: マルチコールバイナリ用のエントリーポイントとサブコマンド振り分け
